# Original SVG design references

These are **original editable vector mockup images** created for the PUBG Console Dashboard project, not downloaded from the previous conversational inspiration image results.

- [Overview reference](./overview-reference.svg) — dark side navigation, KPI hierarchy, chart colours.
- [Leaderboard reference](./leaderboard-reference.svg) — ranking and comparison presentation.

The numeric values in both reference SVGs are *illustrative*, not API data. The actual website loads real cached figures from Supabase via `/api/public-stats`.

Design tokens: navy #081024, panel #15233b, mint #38e4c8, lavender #8875ff, text #f0f5ff. Accessible high-contrast typography with mobile-first fallbacks. Do not add licensed PUBG game imagery without permission.
